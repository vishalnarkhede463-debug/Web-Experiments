HTML Basics

HTML stands for HyperText Markup Language. It is used to create the structure of websites. HTML helps to add:

✔ Headings ✔ Paragraphs ✔ Images ✔ Links ✔ Videos

Example of basic HTML code:

<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>
